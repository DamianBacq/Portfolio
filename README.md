# Portfolio IT: Damián Bacque

Portfolio para buscar trabajo en IT (analista funcional jr o desarrollador full stack jr), para poner en LinkedIn y en el CV.

- **Portada**: nombre, rol, una frase concreta de lo que hice, contacto visible (mail, LinkedIn, GitHub) y una ficha con lo que busco.
- **Pelu Barber** como caso: problema, mi rol, solución y estado, con la compu y el celular. Debajo, un desplegable "Ver cómo lo hice" con reglas de negocio, modelo de datos, arquitectura con endpoints y decisiones técnicas.
- **Más trabajos**: el TP integrador de ADS (análisis funcional) y las tres demos (Ombú, Hocico y Bulón).
- **Habilidades** principales con dónde las usé, **Recorrido** y **Contacto**.

Para mostrar el botón "Descargar CV", guardá el PDF como `public/cv.pdf` y en `src/datos.ts` poné `cv: '/cv.pdf'`.

## Cómo verlo

```
npm install
npm run dev
```

Es solo frontend. Todo el texto está en `src/datos.ts`.
